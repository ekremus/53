# AoE2 Weekly Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish a polished shared tracker for weekly AoE II 4v4 matches.

**Architecture:** A single client page reads and writes a canonical JSON match collection through same-origin route handlers. D1 stores the JSON plus an optimistic revision, while a runtime secret protects edits; all leaderboard and team statistics are derived in the client.

**Tech Stack:** TypeScript, React, CSS, Vinext, Cloudflare Worker runtime, D1, Node test runner.

## Global Constraints

- Keep exactly four named players on each team for every saved match.
- Store only match date, team players, winner, stable id, and persistence metadata.
- Use server-verified password `53` for all mutations.
- Preserve a public, responsive, single-page view with no dashboard clutter.
- Use warm parchment, restrained gold, red, and blue without copying Age of Empires II artwork or UI.
